# Heritage artwork permission request template

Identify the exact upstream repository, commit, filenames, intended public
repository/release/video uses, whether modification is planned, attribution
text, and whether commercial reuse is requested. Ask the rights holder to state
the license or explicit permission in writing. Preserve the complete response,
date, sender identity, scope, and hash as evidence. Do not mark an asset
publishable until the response covers the intended use. This template sends
nothing automatically.

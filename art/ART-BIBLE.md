# NEURAL1 art bible

Use geometry before ornament. Preserve 40-column rhythm, generous empty space,
strong labels, and visible state provenance. FIELD LIBRARY diagrams explain
real paths or evidence. NEURAL1 maps show real run bytes/lineage. META
constellations show typed relations. Use only printable glyphs with stable
meaning. Never imitate or derive unlicensed portraits; record source, author,
rights status, changes, and attribution for every external/derivative asset.

# Apple1 manuals archive

This directory preserves the five PDF files supplied in the collection's
`Manuals and Documentation` folder. They were copied byte-for-byte into
`files/` on 2026-08-29 UTC after the repository owner authorized public GitHub
preservation.

`manuals-manifest.json` records each original filename, byte count, and
SHA-256 value. The copied files matched their source hashes at capture time.

This record does not establish authorship, publication rights, authenticity, or
that any document describes the current Replica 1 Plus hardware. It is an
integrity and provenance record for the supplied working copies only.

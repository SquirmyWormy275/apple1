# Sanyo VM-4209 collection accession packet

**Status:** PRE-ARRIVAL / SELLER CLAIMS NOT YET PHYSICALLY VERIFIED

This packet begins the provenance chain for the acquired Sanyo VM-4209 without
turning an online listing into an authentication record.

## Acquisition source

- **Listing:** https://www.ebay.com/itm/178435032714
- **Object represented:** Sanyo VM-4209 monochrome monitor
- **Seller-stated manufacture date:** February 1979
- **Seller/listing observations to verify on arrival:** model/date label,
  condition, controls, any Apple sticker or marking, connectors and accessories.

The listing is evidence of what was represented at sale. It does not authenticate
an Apple association, date code, sticker age, prior ownership, or originality of
any applied label.

## Pre-arrival rights decision

The seller's listing photographs are **not copied into the repository**. Buying
the monitor does not establish transfer of copyright in the photographs. Keep
the listing URL and transaction records privately as acquisition evidence; use
new owner-made photographs for the public collection record.

## Arrival procedure: documentation only

Before cleaning, testing, connecting, opening, or servicing the monitor:

1. photograph the unopened shipping container from all sides;
2. record carrier label and visible shipping damage without publishing private
   address information;
3. photograph each packing layer during unpacking;
4. photograph all exterior faces of the monitor as received;
5. make close photographs of front logo/badge, controls, CRT face, rear label,
   model, serial/date fields, connectors, cable and plug;
6. photograph any Apple sticker/marking in overall context and close detail;
7. record scratches, corrosion, missing fasteners, replaced controls, stains,
   cracks and other condition evidence before cleaning;
8. retain the original camera files and create derivatives separately.

This is a documentation checklist, **not** an instruction to power or service a
vintage CRT.

A recommended permissive choice for project documentation is **CC BY 4.0**,
but the photographer should make that choice explicitly; no license is assumed
by this template.

## Historical context

The VM-4209 research dossier is at
[`../../peripherals/displays/sanyo/vm-4209.md`](../../peripherals/displays/sanyo/vm-4209.md).
Its core historical finding is deliberately narrower than collector folklore:
the VM-4209 is a genuine early personal-computer/data monitor with a documented
Apple corporate association by the 1978 period and a strong later Apple-1
collector association, but it has not been established as an Apple-supplied
Apple-1 peripheral in 1976.

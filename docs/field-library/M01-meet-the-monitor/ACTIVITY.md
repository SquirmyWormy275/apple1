## Part C: the response that looks wrong

The manual shows this exchange:

```text
300:FF [RETURN]
0300:E1
```

1. What did the user ask for?
2. What does `E1` mean here?
3. Why might a learner think the command failed?
4. How would they check whether it worked, using only the three jobs?

## Part E: the handover

"Run" gives away control and does not get it back automatically. Write two or
three sentences on what that means for someone writing a program for this
machine, and what would happen if their program simply ran off the end of its
own instructions.

## Part F (optional): the tweezers question

The lesson says the Monitor is "closer to a pair of tweezers than to Windows."
Suggest a better analogy, and say what your analogy captures that tweezers
misses.

## What this activity does not do

It reads documented commands on paper. Nothing is typed on any machine and no
hardware action is authorized.

# H06 activity — Build the display-evidence timeline

## Part A — Classify three claims

Use `assets/three-claims.txt`.

For each statement write one label:

- `FACT` — directly supported by strong contemporary/institutional evidence;
- `LATER ASSOCIATION` — true about later collecting or provenance, but not a
  1976 purchasing rule;
- `UNVERIFIED` — plausible/repeated but the needed primary evidence is missing.

## Part B — Put the evidence in order

Place these events in chronological order:

- Apple explains generic composite-monitor / TV use.
- Smithsonian-documented VM-4092 is manufactured.
- Earliest currently recorded VM-4209 specimen.
- VM-4209 is explicitly listed in BYTE computer advertising.
- Apple-property-marked VM-4209 is manufactured.

Then write `PRIMARY`, `INSTITUTIONAL`, or `PROVENANCE` beside the source type.

Complete these sentences:

## Part D — Write the careful answer

> What monitor did the Apple-1 use?

Your answer must include both the 1976 Apple documentation and the later Sanyo
VM-4209 association without calling the Sanyo official.

# S01 Activity: name the three parts

**Status:** OFF-DEVICE. Paper and a text editor only. Do not power on, connect,
or touch the Replica 1 Plus for any part of this activity.

**Time:** 10 minutes for Part A alone, 20 minutes for all three parts.

---

## Part A: label the diagram (this is the first result)

1. Open `assets/three-parts-blank.txt`.
2. Write one of these three names on each blank line, using each name once:

   - the board
   - the monitor
   - the replica

3. Open `assets/three-parts-labeled.txt` and check your three answers.

Stop here if you only have five minutes. You have the result.

---

## Part B: sort the statements

Each statement below is about the board, the monitor, or the replica. Write B,
M, or R next to each one.

| # | Statement | B / M / R |
|---|---|---|
| 1 | It cost $666.66 and you still had to buy a keyboard. | |
| 2 | It is 256 bytes long. | |
| 3 | It was manufactured decades after 1976 and sold with a new user manual. | |
| 4 | It runs the instant you press reset, before you have typed anything. | |
| 5 | About two hundred of them were made in 1976. | |
| 6 | Its ROM also holds BASIC and an assembler. | |

One of these six is harder than the others because it could plausibly describe
two of the three parts. Decide which one that is and write down why you chose
the answer you chose. The answer key names it.

---

## Part C: fix the sentence

Each sentence below misuses a word. Rewrite it so it is accurate. Keep it short.

1. "This Apple-1 was built in 2014."
2. "I plugged in the Apple-1 and the monitor came up on the monitor."
3. "The Woz Monitor is the chip that the Apple-1 boots from."

---

## Part D (optional, 5 minutes): the museum label

Write a label for a Replica 1 Plus on display, in 25 words or fewer, that a
visitor could read without concluding they are looking at an original 1976
Apple-1. A sample is in `ANSWERS.md`, but yours does not have to match it.

---

## What this activity does not do

Completing this activity tells you nothing about whether the physical Replica 1
Plus in this project works. It is a vocabulary and reading exercise. No step
here authorizes a firmware load, an EEPROM write, a CFFA1 write, a serial-port
open, or a physical change to the machine.

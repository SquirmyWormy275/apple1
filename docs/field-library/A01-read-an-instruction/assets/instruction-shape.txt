APPLE-1 FIELD LIBRARY / A01
THE SHAPE OF AN INSTRUCTION

     LDA   #$41
     ---   ----
      |      |
      |      +-- OPERAND: WHAT TO
      |          ACT ON.
      |
      +-- MNEMONIC: WHICH ACTION.

READ IT AS THREE THINGS:

  VERB      LOAD
  WHAT      THE ACCUMULATOR
  WITH      THE NUMBER $41

TWO WAYS TO WRITE THE OPERAND:

  #$41   IMMEDIATE.  THE VALUE
         ITSELF.  THE NUMBER 65.

  $41    ABSOLUTE.  AN ADDRESS.
         WHATEVER IS STORED AT
         LOCATION $0041.

ONE CHARACTER.  ENTIRELY DIFFERENT
MEANING.

THE VERBS YOU NEED FOR NOW:

  LDA   LOAD A FROM ...
  LDX   LOAD X FROM ...
  LDY   LOAD Y FROM ...
  STA   STORE A INTO ...
  STX   STORE X INTO ...
  STY   STORE Y INTO ...
  JMP   GO TO ...

STORE HAS NO IMMEDIATE FORM.
YOU CANNOT STORE INTO A NUMBER.

APPLE-1 FIELD LIBRARY / A03
HOW A BRANCH FINDS ITS TARGET

A BRANCH IS TWO BYTES:

    D0 FD
    -- --
    |   +-- THE OFFSET
    +------ THE BRANCH OPCODE

THE OFFSET IS COUNTED FROM THE
INSTRUCTION AFTER THE BRANCH.

  0303  D0 FD
  0305  <- COUNTING STARTS HERE

  $FD AS A SIGNED BYTE IS -3.

  0305 - 3 = 0302.  TARGET.

SIGNED BYTES:

  $00 TO $7F  ARE  0 TO +127
  $80 TO $FF  ARE  -128 TO -1

  TO READ A NEGATIVE ONE:
    SUBTRACT 256.
    $FD = 253.  253 - 256 = -3.

  BIT 7 SET MEANS NEGATIVE.

RANGE:
  A BRANCH REACHES -128 TO +127
  FROM THE FOLLOWING INSTRUCTION.
  NO FURTHER.  THAT IS WHY LONG
  JUMPS USE JMP INSTEAD.

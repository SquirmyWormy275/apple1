# R03 Activity: write a rule

**Status:** OFF-DEVICE. Paper and pencil, optionally an ordinary computer for the
extension. Nothing runs on the Replica 1 Plus.

## Part A: four rows by hand (this is the first result)

Complete the first grid on `assets/rule-worksheet.txt`, rows 1 to 4, columns 1
to 12, then answer the two questions underneath.

## Part B: the triangle

Complete the number triangle on the worksheet, then mark odd numbers with `#` and
even with a space. Name the shape that appears.

Line 3 is harder. Line 4 has more than one possible answer; give two.

## Part G (optional, off-device extension)

Write a short program on an ordinary computer, in any language, that prints one
of these patterns. Work three rows out by hand first and check the program
against them.

**Do not attempt this on the Replica 1 Plus.** This packet grants no authority to
run anything on it.

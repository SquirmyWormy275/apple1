## Part D: rewrite the listing

Rewrite each so it is accurate. If you cannot make it accurate without
information you do not have, say what information is missing.

2. "Genuine Apple 1 replica, original condition."
3. "Rare Apple-1 board, all original parts, fully restored."

Listing 3 contains a contradiction. Find it.

## Part G (optional, STUDY): the correction letter

You notice a museum label describing a replica as an original. Write three
sentences to the curator. Be right and be kind; both are required.

## What this activity does not do

It uses vocabulary carefully on paper. **It authenticates nothing**, examines no
object, and makes no claim about the value of anything. It authorizes no hardware
action.

# B02 Activity: four boxes

**Status:** OFF-DEVICE. Paper only. No program here is run anywhere.

## Part A: choose a job and draw it (this is the first result)

Pick one. One input, one result.

1. Convert a number of inches to centimetres.
2. Ask for a name and greet the person.
3. Ask for a number and say whether it is over 100.
4. Ask how many hours were worked and report the pay at a fixed rate.
5. Ask a single quiz question and say right or wrong.

Fill in the four lines and the variable fields on `assets/flow-diagram.txt`.

## Part D: write the lines

Write BASIC for job 1 or job 2 from Part A. Four to six lines. Include a `DIM` if
you use a string.

## Part E: what the user sees

Write out the exact screen exchange for your program, including the automatic
question mark. Then read it aloud as though you were the user. Fix anything that
reads badly.

## Part F: the missing DIM

A program uses `N$` without a `DIM` line.

1. What has the programmer not told BASIC?
2. Why does a string need this when an integer does not?
3. What is the largest a string can be?

## Part G (optional): two inputs

Extend your program to take a second input. Redraw the boxes. How many new ways
can it go wrong?

## What this activity does not do

It plans programs on paper. It runs nothing and authorizes no hardware action.

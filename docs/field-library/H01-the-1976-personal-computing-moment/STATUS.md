## Known limitations

- **Four of five cards carry a year only**, because only one source gives a
  month. The order of the two 1976 cards is an inference and the answer key says
  so.
- **This library's sources date only these five events** (V-28). The Altair's
  release, the Apple II's introduction, the Homebrew Computer Club's founding,
  and Gates's Open Letter are all mentioned in the sources and none is dated. A
  wider timeline would need sources this project does not hold.
- The made/sold/purchased distinction (V-2) is load-bearing and must not be
  collapsed into a single figure.

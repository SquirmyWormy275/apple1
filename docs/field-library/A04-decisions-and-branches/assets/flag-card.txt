APPLE-1 FIELD LIBRARY / A04
THE TWO FLAGS YOU NEED

A FLAG IS ONE BIT THE PROCESSOR
SETS AFTER AN INSTRUCTION, SAYING
SOMETHING ABOUT THE RESULT.

  Z   ZERO FLAG
      SET WHEN THE RESULT WAS ZERO.

  N   NEGATIVE FLAG
      SET WHEN BIT 7 OF THE RESULT
      WAS 1.

CMP #$D9 DOES A SUBTRACTION IT
THROWS AWAY.  IT KEEPS ONLY THE
FLAGS.

  IF A EQUALS $D9,
    A - $D9 IS ZERO,
    SO Z IS SET.

  IF A IS ANYTHING ELSE,
    THE RESULT IS NOT ZERO,
    SO Z IS CLEAR.

A IS NOT CHANGED BY CMP.

BRANCHES THAT READ THESE FLAGS:

  BEQ   BRANCH IF Z IS SET
        (RESULT WAS ZERO)
  BNE   BRANCH IF Z IS CLEAR
  BMI   BRANCH IF N IS SET
  BPL   BRANCH IF N IS CLEAR

"EQ" AND "NE" ARE ABOUT ZERO.
AFTER A CMP, ZERO MEANS EQUAL.

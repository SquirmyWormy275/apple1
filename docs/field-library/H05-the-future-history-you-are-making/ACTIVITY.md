# H05 Activity: write one entry

**Status:** OFF-DEVICE. Paper only. Writing a log entry does not authorize
anything it might describe.

## Part A: today's entry (this is the first result)

Fill `assets/log-entry.txt` about something you did today with this project.
Reading a lesson counts. Fill in all six fields, including "what I am not sure
about."

## Part B: separate the three

Split each sentence into what was done, what was seen, and what it was taken to
mean.

| # | Sentence | Did / Saw / Meant |
|---|---|---|
| 1 | "Opened the port and the display garbled, so the serial path is broken." | |
| 2 | "Ran the emulator and it returned to the monitor, so the program works." | |
| 3 | "Pressed reset and got a backslash, so the ROM is fine." | |

For each, say which part would still be true in five years.

## Part C: what is missing

This entry is real in shape and poor in content.

> "Worked on the Apple 1 today. Tried a few things. Seems better now."

List every field from the card that it fails to supply.

## Part D: the ambiguous gap

A log has no entries for three weeks.

1. Name two things that could mean.
2. How would one line have removed the ambiguity?
3. What is the cost of that line?

## Part E: worth logging

| # | Item | Log it? |
|---|---|---|

| 3 | The version of a document you followed | |
| 4 | A day spent only reading | |
| 5 | A guess you later found was wrong | |

Items 5 and 6 are the same question. Answer it honestly.

## Part F: read your own old notes

Find any note you wrote more than a year ago about anything. Mark every place you
cannot now tell whether something was observed or assumed. Count them.

## Part G (optional): the entry you would want to find

Imagine somebody picks up this project in twenty years. Write the one log entry
you most wish existed but does not. Then consider writing the equivalent for
today.

## What this activity does not do

It writes records on paper. It authorizes no hardware action, and describing an
action in a log does not permit it.

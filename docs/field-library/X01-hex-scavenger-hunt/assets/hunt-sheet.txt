DUMP TWO IS INVENTED FOR THIS
PUZZLE.  IT IS NOT A READING FROM
ANY MACHINE.

  0400: D7 C5 CC CC A0 C4 CF CE
  0408: C5 8D 00 00 00 00 00 00

HINTS

  H1  AN ADDRESS IN AN INSTRUCTION
      IS STORED LOW BYTE FIRST.
  H2  4C IS A JUMP.  20 IS A CALL.
  H3  KEYBOARD BYTES HAVE BIT 7
      SET.  SUBTRACT $80 FIRST.
  H4  COUNT ADDRESSES FROM THE
      LINE LABEL, NOT FROM 1.
  H5  THE LAST INSTRUCTION IS
      THREE BYTES LONG.

$D010  KEYBOARD DATA
$D011  KEYBOARD CONTROL
$D012  DISPLAY DATA
$D013  DISPLAY CONTROL

I/O AT THESE LOCATIONS.

           |
           V
       $D010-$D013
           |
           V

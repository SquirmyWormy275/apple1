APPLE-1 FIELD LIBRARY / S02
ONE KEYPRESS, END TO END

  YOU PRESS THE KEY  A
          |
          V
[1] INPUT
    THE KEYBOARD PUTS A NUMBER ON ITS
    WIRES AND PULSES A "READY" WIRE.
          |
          V
[2] A MAILBOX
    THE NUMBER WAITS IN A NUMBERED
    SLOT.  A SECOND SLOT HOLDS A FLAG
    SAYING "SOMETHING IS WAITING".
          |
          V
[3] PROCESSING
    THE CPU CHECKS THE FLAG SLOT OVER
    AND OVER.  WHEN IT IS SET, THE CPU
    READS THE NUMBER OUT.
          |
          V
[4] MEMORY
    THE CPU PUTS A COPY OF THE NUMBER
    IN A SLOT IT CHOSE, SO IT CAN USE
    IT AGAIN LATER.
          |
          V
[5] OUTPUT
    THE CPU WAITS UNTIL THE DISPLAY
    SLOT IS FREE, THEN PUTS THE NUMBER
    THERE.  THE VIDEO PART TURNS IT
    INTO THE SHAPE OF A LETTER.
          |
          V
       YOU SEE  A

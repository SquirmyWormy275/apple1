APPLE-1 FIELD LIBRARY / B01
THE SAME JOB, TWO WAYS

JOB: PRINT A MESSAGE.

IN BASIC:

  10 PRINT "HELLO WORLD"
  20 END

IN 6502, ROUGHLY:

  SET UP A POINTER TO THE TEXT
  LOOP:
    LOAD THE NEXT CHARACTER
    IF IT IS THE END MARKER, STOP
    CALL THE DISPLAY ROUTINE
    ADVANCE THE POINTER
    GO BACK TO LOOP
  PLUS THE TEXT ITSELF, ONE BYTE
  PER CHARACTER, WITH A MARKER.

WHAT BASIC DID FOR YOU:
  FOUND THE TEXT
  WALKED THROUGH IT
  KNEW WHERE IT ENDED
  CALLED THE DISPLAY
  RETURNED WHEN DONE

WHAT IT COST YOU:
  BASIC MUST BE PRESENT
  IT DECIDES HOW, NOT YOU
  IT IS SLOWER
  IT USES MORE MEMORY

NEITHER IS BETTER.
THEY TRADE DIFFERENT THINGS.

  ASSEMBLY GIVES YOU CONTROL AND
  CHARGES YOU IN DETAIL.

  BASIC GIVES YOU SPEED OF WRITING
  AND CHARGES YOU IN CONTROL.

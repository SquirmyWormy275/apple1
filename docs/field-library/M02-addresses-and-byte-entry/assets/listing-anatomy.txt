APPLE-1 FIELD LIBRARY / M02
ANATOMY OF A BYTE LISTING

A MONITOR-STYLE LISTING LOOKS LIKE
THIS.  THIS EXAMPLE IS INVENTED FOR
TEACHING AND IS NOT A REAL PROGRAM.

   0300: A9 01 8D 00 04 4C 1F FF
   ^^^^  ^^ ^^^^^^^^^^^^^^^^^^^^
    |    |         |
    |    |         +-- THE REST OF
    |    |             THE BYTES
    |    |
    |    +-- THE FIRST BYTE.  IT
    |        LIVES AT THE ADDRESS
    |        ON THE LEFT.
    |
    +-- THE LOAD ADDRESS.  WHERE THE
        FIRST BYTE GOES.

EACH BYTE AFTER THE FIRST GOES ONE
ADDRESS FURTHER ALONG:

   0300  A9
   0301  01
   0302  8D
   0303  00
   0304  04
   0305  4C
   0306  1F
   0307  FF

THE ADDRESS IS NOT PART OF THE
PROGRAM.  IT IS WHERE THE PROGRAM
GOES.  THE SAME BYTES AT A DIFFERENT
ADDRESS ARE A DIFFERENT PROGRAM.

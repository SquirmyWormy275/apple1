# Heritage rights-clearance workflow

Five required concepts remain blocked: Apple emblem, Wozniak portrait, Jobs
portrait, combined Jobs/Woz plate, and Apple-1 origins sequence. A candidate can
be marked publishable only when intended-use permission/license evidence is
retained. External and derivative candidates require source IDs and attribution.
The registry rejects `NOT_ESTABLISHED` or `UNKNOWN` rights for publication.

`art/provenance/PERMISSION-REQUEST-TEMPLATE.md` defines the information to seek;
it sends no message. The Schmenk reference record remains non-publishable and
no upstream visual is vendored.

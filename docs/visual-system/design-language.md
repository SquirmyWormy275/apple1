# Apple-1 visual system

The portal is a threshold, the Field Library a living technical archive,
NEURAL1 a window into constrained worlds, and META/1 a constellation of claims
and evidence. Art should communicate state or structure, not fill space.
Machine-facing frames use upper-case printable ASCII, maximum 40 columns,
deterministic rendering, and explicit pagination. `validate_frame` enforces the
policy; unsupported characters fail rather than disappear.

Data-driven families include occupancy maps, 16x16 ROM genomes, SELFHOST towers,
shared-memory boundaries, candidate-machine block diagrams, claim constellations,
and run sigils. Every preview is virtual until physically qualified.

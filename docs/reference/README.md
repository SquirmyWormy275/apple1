# Reference sources

Use the Briel Replica 1 Plus manual as the local operating reference:

- 9600 baud, 8 data bits, one stop bit, no parity, no flow control;
- initial pacing target of 50 ms per character and 200 ms per line;
- firmware is upgradeable, but its source/manual statements do not prove the
  currently installed EEPROM image.

Record the original manual's filename, edition, and SHA-256 before copying it
into this repository. Do not replace the source document with an extracted or
rewritten version.

## Heritage artwork reference

The Apple-1 visual system uses David Schmenk's `Apple1-Slideshow` as a heritage
quality and format reference. See:

- [Apple1-Slideshow provenance and attribution](apple1-slideshow.md)
- [Machine-readable source record](apple1-slideshow-source.json)

The upstream revision is pinned to
`d436e3b088f94919f135e48af6303295058b3d51` (2014-12-04). The upstream
repository documents a 40 x 23 Apple-1 artwork workflow and includes the
well-known Jobs/Woz and Apple-logo slideshow assets.

**License/redistribution status is not established.** Do not vendor or publish
the exact upstream artwork from this repository until permission or applicable
license terms are established. Any use or derivative must preserve explicit
attribution to David Schmenk, the upstream repository, the source filename, and
the pinned revision.

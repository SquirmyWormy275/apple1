# Reference sources

Use the Briel Replica 1 Plus manual as the local operating reference:

- 9600 baud, 8 data bits, one stop bit, no parity, no flow control;
- initial pacing target of 50 ms per character and 200 ms per line;
- firmware is upgradeable, but its source/manual statements do not prove the
  currently installed EEPROM image.

Record the original manual's filename, edition, and SHA-256 before copying it
into this repository. Do not replace the source document with an extracted or
rewritten version.

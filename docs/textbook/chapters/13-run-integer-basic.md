# 13. Execute a real Integer BASIC interpreter

Follow the [worked BASIC chapter](../reference/basic.md). Run U01–U06 in order:
a greeting, a bounded converter, a running sum, a complete sort, a quiz and a
generated pattern.

Before each run, predict an observable result. Afterward, identify the
interpreter binary, the input script, the output and the stop reason.
Explain how one-based arrays, string allocation and intermediate overflow
differ from the Python analogues in the earlier B-series companions.

Finish with K04: save the actual tokenized program, clear RAM, restore the BA1
and execute it. Passing that exercise connects language, memory and files.
It still does not identify the interpreter installed in the physical board.

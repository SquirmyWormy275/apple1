# 8. Ask questions the evaluator can answer

A memorable experiment name is not its success criterion. Begin with the
observable task, the controlled factors, a falsifying case, and the evidence you
must retain. A valid negative result is useful when it reveals a boundary.

## The five families

| Family | Concrete starting question | Worked example |
|---|---|---|
| 4K MIND | Can a known routine execute and be independently checked in a constrained RAM world? | [F08](../features/F08.md) |
| SELFHOST/1 | Can a raw artifact meet stage-one execution criteria? | [F09](../features/F09.md) |
| 256-BYTE UNIVERSE | Can an explicitly deposited exact-size candidate meet an output/return task? | [F10](../features/F10.md) |
| RAM REPUBLIC | Can authored participants interact through shared RAM under the family evaluator? | [F11](../features/F11.md) |
| 1976 MULTIVERSE | Does a proposal have enough valid sourced structure to pass? | [F12](../features/F12.md) |

The first four use authored virtual fixtures; the historical example intentionally
fails with no proposals. None is a discovered toolchain, communication protocol,
complete Monitor, or historical machine. L08 supplies a positive/negative pair
for the exact-256 task.

## Freeze the criterion before looking at results

Suppose the task is to output A and reach Monitor warm entry. A candidate that
outputs B fails, even if the model explains why B is interesting. A candidate
that outputs A and then escapes its memory policy also fails. A criterion should
not be relaxed after seeing a favorite result.

Control the model identity, initial state, seeds, budget, prompts, and parser
version. L07 makes a matrix explicit: models times families times seeds gives
cells; generations and agents multiply turns inside them. Resource limits can
stop a planned comparison before it is informative.

## Read an incomplete experiment honestly

Historical Pilot 001 recorded 156 turns and zero strict-parser acceptances; six
of 45 cells completed before a thermal stop left the matrix incomplete. That is
a negative result for the tested configuration, not proof that all those model
families can never use the Monitor. Read its
[limitations](../../neural1/research/pilot-001/limitations.md).

Later native Pi acceptance used a different recorded configuration. It supports
its bounded operational observations; it does not rewrite Pilot 001. F16 reads
one public native evidence extract without rerunning that machine.

## Historical claims need a separate discipline

The broad March-1976 index is staging. The console's small reviewed year-end
corpus has a different cutoff and scope. Missing prices stay null. An LLM can
suggest a research question but cannot promote invented prices or electrical
compatibility into authoritative data. F26 reads the status without changing it.

## Practice

Write a one-page experiment card: question, fixed factors, changed factor,
positive control, negative control, stopping rule, record fields, and allowed
conclusion. Include the conclusion you must decline if the run stops halfway.
Use the project's [methods](../../neural1/research/methodology.md) and
[controls](../../neural1/research/experimental-controls.md) as the deeper references.

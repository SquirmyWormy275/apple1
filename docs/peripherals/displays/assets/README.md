# Visual assets

The display-history dossier currently uses externally hosted historical images
from Wikimedia Commons in `../visual-chronology.md` rather than duplicating
binary media in the repository through this documentation update.

Only images whose rights were reviewed are embedded:

- 1976 Apple-1 advertisement — U.S. public-domain status recorded by Commons;
- December 1977 Apple II advertisement pages — U.S. public-domain status
  recorded by Commons;
- 2023 Apple-1 museum photograph by The wub — CC BY-SA 4.0.

Sanyo museum/auction/seller photographs are intentionally **not** copied because
reuse permission was not established. See `../image-rights-ledger.md`.

Future owner-made photographs of the acquired VM-4209 should be recorded under
`../../../collection/sanyo-vm-4209-1979/` with an explicit license.

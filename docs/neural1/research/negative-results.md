# Negative results register

Failed runs, rejected hypotheses, extinctions, non-replications, invalid source
assumptions, provider errors, and unsupported claims belong here or in linked
immutable records. Each entry must name the run/spec, failure classification,
available artifacts, whether retry is justified, and what was learned.

## Recorded results

- [Pilot 001](pilot-001/negative-results.md) retains parser rejection, thermal
  cancellation, and the incomplete experiment matrix. The
  [pilot report](pilot-001/README.md) explains the bounded interpretation.
- [Native Pi closeout](../operations/pi-closeout-2026-09-10.md) retains rejected
  candidates, negative family outcomes, earlier failures, and operational limits.
  It is a separate record from the historical pilot.

For an introduction, see the [wiki's negative-results guide](../../../wiki/Negative-Results.md).
Deterministic fixture failures remain software-test output, distinct from
model experiment results.

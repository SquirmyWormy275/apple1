# Threats to validity

Principal threats include emulator/model mismatch, prompt leakage, selection
and survivorship bias, post-hoc metrics, seed artifacts, model-family dependence,
classifier drift, inaccurate lineage attribution, hidden host affordances,
uncontrolled scheduler effects, and historical-source gaps. Mitigations include
blinding, pre-registration, complete error retention, controlled replay,
intervention, cross-seed/model replication, explicit classifier versions, and
event-level provenance.

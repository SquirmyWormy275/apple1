# Limitations

This is one bounded workstation pilot using three small quantized model families. It does not establish physical Apple-1 behavior, causal effects, historical facts, broad model-family generality, or autonomous culture. Missing token/backend metadata remains missing. Deadline-truncated cells are not treated as failures unless the metric defines them that way.

Thermal cancellation left 39 matrix cells incomplete or unstarted. TinyLlama
has no completed cell, and four experiment families have no turns. The parser
measures syntactic WozMon actions, not latent understanding. Prompts were
minimal, no few-shot valid command example was seeded, and model-specific chat
templates differ. The cell iteration order concentrates early evidence in 4K
MIND and should be blocked/randomized in a successor campaign. Host sensor
sampling was 30 seconds and one thermal zone occasionally reported an invalid
near-1 C value; named TCPU/package sensors, not that sensor, caused the stop.

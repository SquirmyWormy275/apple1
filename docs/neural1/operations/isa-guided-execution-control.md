# ISA-guided execution control

Historical v2 proposal; superseded by the [instruction-guided format control](guided-format-execution-control.md). The unsuccessful evidence described here is preserved.

Status: **UNQUALIFIED — NATIVE ACCEPTANCE PENDING**. Recorded Qwen and Phi
provider probes have not established the required complete accepted execution.
The Pi became unreachable before this revision could be accepted. Preserve all
negative records; do not treat these source changes as a successful deployment.

The bounded machine preset source explicitly identifies these tasks as
**ISA-guided execution controls**. They supply the NMOS encodings for
LDA immediate, JSR and JMP, the ASCII value of A, the Monitor API addresses, and
the known eight-byte output/return baseline. The model is asked to return only
three Monitor lines: deposit, examine and run. This follows a recorded genuine
Pi attempt that produced oversized deposits/prose and no accepted execution.
That failed attempt remains historical evidence.

The model still generates every response through the real provider. No baseline
is inserted into the world by application code, no rejected response is replaced,
and parser/evaluator rules are unchanged. A successful acceptance would prove
the bounded inference, strict parsing and virtual execution path; they do not establish autonomous
program discovery. Prompts and actual responses retain the supplied treatment.

The exact256 control instead requests sixteen sixteen-byte deposits followed by
examine and run. Its eight-byte baseline is explicitly padded by the model with
248 zero bytes. This respects the 32-command parser bound and existing 1024-token
output cap. Incomplete/truncated deposits remain rejected; the application never
fills missing bytes. Existing CPU memory-policy checks still apply. This is an
ISA-guided executable candidate, not a blinded replacement-monitor experiment.

4K preserves the world and lineage across generation/context resets; RAM
REPUBLIC exposes only its declared shared examination and each participant's own
feedback. Sharing the disclosed baseline is the named control, not evidence for
an emergent protocol. SELFHOST qualifies raw stage 1 only until independent
persistent ancestry, rebuild and behavioral qualification supports a later stage.

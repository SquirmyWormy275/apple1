# META/1 architecture

META/1 treats the claim—not chat—as its primary object. Claims link to evidence,
runs, artifacts, and other claims through typed relations. Evidence carries a
causal-evidence level. Proof capsules flatten a supported claim into hashes,
run IDs, causal tests, uncertainty, counterexamples, analysis version, and a
reproduction command. Natural-language interfaces may explain these records;
they may not manufacture them.

# Physical boundary

The confirmed STOP is authoritative: a payload-free FT232R open garbled the
display, and Reset recovered the Monitor. NEURAL1 contains no serial import,
firmware loader, EEPROM writer, CFFA1 writer, GPIO controller, or camera path.
`PhysicalQualificationAdapter.available` is false and `launch()` raises.

Physical work remains blocked until repository-defined commissioning gates
explicitly supersede the STOP. Generated/evolutionary programs must never flow
automatically to a physical machine. Physical qualification, if later approved,
is a narrow test of a named artifact—not general physical experiment execution.

# 4K MIND

Agents receive only modeled WozMon transactions. They have no shell, Python,
assembler, debugger, semantic memory API, or privileged RAM access. A colony
combines an isolated world and scheduled population. Context reset constructs a
new logical context around the preserved RAM snapshot; successful bytes may be
inherited through explicit lineage policy. Catastrophes delete or XOR a named
range and record generation/address/length. Migration and archaeology should
reuse artifact and snapshot records; selection metrics must be predeclared.

Current prototype deposits/examines bytes, advances generations, snapshots RAM,
records lineage, and performs disturbances. It does not yet conduct autonomous
LLM evolution or execute deposited code.

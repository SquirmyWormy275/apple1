# RAM REPUBLIC

Logical agents have private context and scheduled turns against one WozMon
session/world. There is no host-side agent chat. Communication must therefore
appear in allowed RAM state. Controlled experiments may vary noisy-agent rate,
context resets, newcomers, and observation permissions without seeding a
mailbox/lock/checksum convention unless that is the named treatment.

Measure time to protocol identification, first compatible message, routine use,
compatible contribution, conflicts, corruption recovery, and failure. The
prototype proves shared-memory scheduling only, not emergent protocol discovery.

# Invariants and concept evolution

Invariant mining declares the population of runs and classifier before seeking
structures stable across models, seeds, ROMs, budgets, tasks, and modes.
`BREAK` compiles a search for a counterexample. Concept records cover checksum,
jump table, calling convention, language, mailbox, lock, memory map, assembler,
compiler, and protocol; classifications are versioned and distinguish inherited,
independent, and uncertain appearance.

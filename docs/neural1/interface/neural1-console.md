# NEURAL1 and META/1 consoles

The compact vocabulary reserves `[V]` virtual, `[P]` physical qualification,
and `[M]` META result. NEURAL1 commands select 4K MIND, 1976 MULTIVERSE,
SELFHOST/1, 256-BYTE UNIVERSE, RAM REPUBLIC, research status, and artifacts.
META commands are ASK, WHY, PROVE, ATTACK, FALSIFY, COMPARE, INVARIANT,
DISCOVER, FORECAST, HISTORY, BLIND, FORK, REPLAY, and TEST. Responses wrap at
40 columns and return insufficient evidence rather than fabricate results.

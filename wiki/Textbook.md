# Learn the machine, then inspect the evidence

The [worked textbook](../docs/textbook/README.md) has **15 chapters and 110
executable examples**. It starts with bytes, memory and the Monitor, moves
through 6502 assembly and local models, then connects actual interpreter and
card-firmware execution to a reproducible exhibit.

| Your goal | Start here |
|---|---|
| New to early computing | [Chapter 0 and the first result](../docs/textbook/chapters/00-how-to-use-this-book.md) |
| Learn assembly | [Assembly chapter](../docs/textbook/chapters/04-assembly-and-control-flow.md), T01–T12 |
| Understand local models | [Local-model chapter](../docs/textbook/chapters/07-local-models.md), L01–L08 |
| Inspect real local inference | [Native walkthrough](../docs/textbook/native/README.md), N01/N02 |
| Run real Integer BASIC | [BASIC chapter](../docs/textbook/reference/basic.md), U01–U06 |
| Review the card work | [Core card guide](../cf-card/README.md), K01–K04 |
| Teach the course | [Course guide](../docs/textbook/course-guide.md), all 42 original packet companions |
| Follow the physical build | [Storyboard and evidence kit](../docs/hardware/build-storyboard/README.md) |

Each catalog example supplies source, captured stdout, an image, checks, a
practice question and an answer. Evidence modes distinguish authored fixtures,
virtual CPU execution, preserved interpreter/firmware execution, and retained
native model output. Physical acceptance remains a separate result.

The core card edition has 50 numbered books, every original lesson's reading,
activity and answers, all 39 board-atlas plates, a RAM reader and six actual BA1
programs. Its full page sequence runs through the real CFFA1 ROM and pager
against modeled I/O. Exact host sources and later-lab artifacts remain available
in the repository; guided summaries on the card do not replace them.

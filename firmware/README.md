# Replica 1 Plus firmware

Use the [staged recovery package](recovery/110REV03-2026-10-28/README.md) for the
built vendor-baseline images, laptop tools, offline rebuild, hashes and future
loading procedure. [Download the self-contained bundle](recovery/releases/README.md).

The [original vendor source](vendor/110REV03/provenance.json) remains unchanged.
The recovery package is built and checked off-device; physical compatibility,
power/reset checks and on-board recovery are pending. The original EEPROM stays
preserved. Follow the [bounded repair plan](../docs/hardware/replica-repair-plan.md)
and [issue #17](https://github.com/SquirmyWormy275/apple1/issues/17).

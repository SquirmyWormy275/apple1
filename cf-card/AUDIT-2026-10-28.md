# Combined CF-card installation — October 28, 2026

The reviewed core and full reading supplements are now installed on the original
Lexar CF card. The complete **128,974,848-byte physical-card readback** matches
the checked image. All six original files, their metadata, original allocated
data blocks, boot blocks and bytes beyond the original volume are unchanged.

The supplements cover all 15 textbook chapters, 42 worked companions, complete
additional-lab text, captured outputs, teacher/visitor material, program

`SOURCE.ZIP` and `BUILD.JSON` are offboard data, not CFFA1-loadable books.
The indexes and combined `START.HERE` guide label that distinction. Python and
model inference run on the modern host; model weights and the large scanned
manual collection remain host resources.

## Verification performed

- **498 repository tests passed**, with Ruff, mypy and repository validation.
  The core also passed workstation, Pi and clean-checkout verification.
- All **110 examples** reproduced their captured output after a fresh
  extraction of the final exact-source ZIP. All 2,843 archived source hashes
  matched the component manifest.
- Every main and supplemental page matched actual NMOS 6502 execution.
  Main answer jumps, navigation, malformed-book guards and Monitor exit were
  checked; supplemental glyph and memory-write bounds were checked.
- The identified CFFA1 ROM loaded all **321 supplemental binaries**, including
  the two RAM demonstrations, from the combined virtual card. All six BA1
  programs restored into cleared BASIC state and ran with output matching
  their cold source sessions. The readers made **zero card writes**.
- CiderPress II appended the supplements to a copy of the reviewed core image.
  Two independent ProDOS inspectors checked all file bytes/types/auxiliary
  addresses, allocation ownership, directory links and preservation boundaries.
- Immediately before writing, a complete live-card read matched the prior
  verified installation. A new complete backup and independent RAM copy were
  verified. Only changed sectors were written; writes were flushed and the
  write handle closed.
- The CF card was reopened, its read cache evicted, and every byte read again.
  The readback matched the combined image, and the independent file/allocation
  checks passed on that physical readback. All original allocated blocks except
  the necessarily updated root directory and allocation bitmap are identical.

The before-update backup, combined image, readback, manifests, source-archive
checks, runtime results and catalogs are retained under
`~/.local/state/apple1-cf-card/20261028/`. The August original and October 27
installation records remain preserved separately.

## Scope of the result

The physical **storage copy** is verified. The CF card was in the USB reader;
no physical Replica display/keyboard session, serial operation, firmware update
or EEPROM write was performed. Those hardware acceptance items remain open.
Historical, rights and source-review qualifications remain in their own records.

The original maintenance tools are retained legacy files, not lesson launchers.
See [the combined reading guide](../wiki/CF-Card-Library.md) for the `$0800`
main reader, `$1000` supplements and saved BASIC workflow.

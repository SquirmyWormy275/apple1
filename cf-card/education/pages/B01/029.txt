THE ASSEMBLER COMPUTES THE OFFSET,
WHICH REMOVES AN ENTIRE CLASS OF THE
ERRORS A03 WAS ABOUT. LABELS MEAN
INSERTING AN INSTRUCTION NO LONGER
REQUIRES RECALCULATING EVERY ADDRESS
AFTER IT.

WHAT IT DOES NOT CHANGE: THE PROGRAM
IS STILL ASSEMBLY. IT RUNS AT THE SAME
SPEED, USES THE SAME MEMORY, REQUIRES
THE SAME UNDERSTANDING OF REGISTERS
AND ADDRESSING, AND CAN REACH THE
HARDWARE JUST AS DIRECTLY. AN
ASSEMBLER CHANGES HOW YOU *WRITE* THE
PROGRAM, NOT WHAT THE PROGRAM *IS*.

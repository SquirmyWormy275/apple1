APPLE-1 FIELD LIBRARY / B01
THE SAME JOB, TWO WAYS

JOB: PRINT A MESSAGE.

IN BASIC:

  10 PRINT "HELLO WORLD"
  20 END

IN 6502, ROUGHLY:

  SET UP A POINTER TO THE TEXT
  LOOP:
    LOAD THE NEXT CHARACTER
    IF IT IS THE END MARKER, STOP
    CALL THE DISPLAY ROUTINE
    ADVANCE THE POINTER

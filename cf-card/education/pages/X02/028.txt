AND THE SPEC IS THE BUG.

THE HONEST PROCEDURE IS TO FIND OUT
WHICH WAS INTENDED, NOT TO PICK
WHICHEVER IS EASIER TO CHANGE. WHAT
MAKES IT A *WRONG FIX* IS DOING IT
SILENTLY, BECAUSE CHANGING THE
SPECIFICATION TO MATCH THE CODE MAKES
ANY CODE CORRECT.

THE QUESTION TO ASK: DOES ANYTHING
ELSE DEPEND ON THERE BEING FIVE? IF
THE BUFFER IS READ BY SOMETHING
EXPECTING FIVE, THE SPEC IS RIGHT AND
THE CODE IS WRONG. IF NOTHING DOES,
SOMEBODY HAS TO DECIDE.

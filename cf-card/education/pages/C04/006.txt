THIS IS A CONVENTION, NOT A LAW OF
NATURE. THE LETTER DID NOT CHANGE.
NOTHING ABOUT ASCII CHANGED. A
PARTICULAR MACHINE'S INPUT PATH SETS A
SPARE BIT, AND PROGRAMS WRITTEN FOR
THAT MACHINE EXPECT IT. READ A BYTE
LIST FROM THIS REPOSITORY AND YOU WILL
SEE $8D WHERE YOU EXPECTED $0D, AND
THE REASON IS THIS AND ONLY THIS.

READING A BYTE LIST BACK AS TEXT.
STRIP THE TOP BIT, THEN LOOK UP THE
RESULT. C8 MINUS $80 IS $48, WHICH IS
H. DO IT ACROSS A LIST AND WORDS
APPEAR. DOING IT IN THE OTHER ORDER,
LOOKING UP $C8 IN AN ASCII TABLE, GETS
YOU NOTHING, BECAUSE ASCII DOES NOT
ASSIGN ANYTHING TO 200.

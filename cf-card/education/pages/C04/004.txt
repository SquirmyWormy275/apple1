C04 CHARACTERS BECOME NUMBERS
004/030 LEARN


ASCII IS AN AGREEMENT. THE AMERICAN
STANDARD CODE FOR INFORMATION
INTERCHANGE ASSIGNS A NUMBER TO EACH
CHARACTER: A IS 65, B IS 66, SPACE IS
32, CARRIAGE RETURN IS 13. IT ASSIGNS
DECIMAL 0 THROUGH 127 ONLY, WHICH IS
HALF OF WHAT A BYTE CAN HOLD.
EVERYTHING ABOVE 127 IS UNASSIGNED BY
THE STANDARD.

TWO CONSEQUENCES FOLLOW, AND BOTH
MATTER HERE.

FIRST, LETTERS ARE CONSECUTIVE. A IS
65 AND B IS 66, SO YOU CAN GET FROM A
LETTER TO THE NEXT ONE BY ADDING 1.
THE DIGITS ARE CONSECUTIVE TOO: 0 IS
N NEXT P BACK A ANSWER M BOOK Q EXIT

007/029 LEARN

LISTING.

THIS MATTERS MORE THAN IT SOUNDS. A
LABEL CAN BE RENAMED WITH NO EFFECT ON
THE PROGRAM. AN ADDRESS CANNOT BE
CHANGED WITHOUT CHANGING THE BYTES.
WHEN SOMEONE SAYS "JUMP TO GETLINE,"
THE MACHINE IS DOING JMP $FF1F AND THE
NAME IS SCAFFOLDING. IF YOU ARE
TRANSCRIBING BYTES, LABELS ARE THE
PART YOU THROW AWAY.

CHOOSING WHERE TO PUT THINGS. THE
PROGRAMS HERE USE $0400. NOTHING MAKES
THAT ADDRESS SPECIAL. IT NEEDS TO BE
RAM, IT NEEDS TO BE SOMEWHERE THE
PROGRAM ITSELF IS NOT, AND IT NEEDS TO
BE SOMEWHERE NOTHING ELSE IS USING.

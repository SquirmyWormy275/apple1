022/029 ANSWERS


PART D: LABEL OR ADDRESS

 /  #  /  ITEM  /  WHICH  /
 /  1  /  $FF1F  /  ADDRESS  /
 /  2  /  GETLINE  /  LABEL  /
 /  3  /  $0400  /  ADDRESS  /
 /  4  /  ECHO  /  LABEL  /
 /  5  /  NOTCR  /  LABEL  /

ADDRESSES APPEAR IN THE BYTES. LABELS
DO NOT. JMP $FF1F ASSEMBLES TO 4C 1F
FF, AND THE 1F FF IS THE ADDRESS.
NOTHING ANYWHERE IN THE BYTE LIST
SPELLS GETLINE. DELETE EVERY LABEL
FROM A LISTING AND THE PROGRAM IS
UNCHANGED; DELETE AN ADDRESS AND IT IS
BROKEN.

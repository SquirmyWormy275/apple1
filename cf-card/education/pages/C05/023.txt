0302  /
 /  2  /  ADC #$01  /  $42 OR $43  /
?  /  0304  /
 /  3  /  STA $0400  /  $42 OR $43
(UNCHANGED)  /  SAME AS A  /  0307  /
 /  4  /  JMP $FF1F  /  UNCHANGED  /
UNCHANGED  /  FF1F  /

STEP 2 IS THE POINT OF THE EXERCISE.
ADC ADDS THE OPERAND *AND THE CARRY
BIT*. THIS PROGRAM NEVER CLEARED THE
CARRY, SO A IS $42 IF THE CARRY WAS
CLEAR AND $43 IF IT WAS SET. A TRACE
THAT WRITES ONLY $42 HAS ASSUMED
SOMETHING THE PROGRAM DID NOT
ESTABLISH.

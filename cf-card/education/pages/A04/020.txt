020/033 WORKSHEET FLAG-CARD.TXT

  IF A EQUALS $D9,
    A - $D9 IS ZERO,
    SO Z IS SET.

  IF A IS ANYTHING ELSE,
    THE RESULT IS NOT ZERO,
    SO Z IS CLEAR.

A IS NOT CHANGED BY CMP.

BRANCHES THAT READ THESE FLAGS:

  BEQ   BRANCH IF Z IS SET
        (RESULT WAS ZERO)
  BNE   BRANCH IF Z IS CLEAR
  BMI   BRANCH IF N IS SET
  BPL   BRANCH IF N IS CLEAR

 /  $D9  /  CMP #$59  /  CLEAR. $D9
AND $59 DIFFER BY BIT 7.  /
 /  $05  /  DEX (X = 1)  /  SET, AND A
IS IRRELEVANT.  /

THE TRAP IN THE LAST ROW: DEX OPERATES
ON X, NOT A. IT SETS THE FLAGS FROM
X'S NEW VALUE, WHICH IS 0, SO THE ZERO
FLAG IS SET. THE VALUE IN A HAS
NOTHING TO DO WITH IT. FLAGS DESCRIBE
THE RESULT OF THE LAST INSTRUCTION
THAT SETS THEM, NOT THE ACCUMULATOR
SPECIFICALLY.

IT THAT HIMSELF, DESCRIBING A SHORT
PROGRAM THAT WATCHED THE KEYBOARD AND
DID THE JOB THE OLD FRONT-PANEL
SWITCHES USED TO DO. IT IS 256 BYTES.
NOT 256 KILOBYTES, AND NOT 256
MEGABYTES: 256 INDIVIDUAL BYTES, ABOUT
THE SIZE OF A SHORT PARAGRAPH OF TEXT.
IT LIVES IN *ROM*, READ-ONLY MEMORY,
WHICH IS MEMORY THAT KEEPS ITS
CONTENTS WHEN THE POWER IS OFF. THE
MONITOR DOES THREE THINGS AND NO MORE:
IT CAN SHOW YOU WHAT IS STORED AT A
MEMORY ADDRESS, CHANGE WHAT IS STORED
THERE, AND START RUNNING A PROGRAM AT
AN ADDRESS. IT IS A TINY TOOLSET, NOT
AN OPERATING SYSTEM.

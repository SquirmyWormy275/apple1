C01 THE 6502 AT WORK
019/026 ANSWERS

C01 ANSWER KEY

PART A

 /  INSTRUCTION  /  ENGLISH  /
 /  LDA #$00  /  LOAD THE ACCUMULATOR
WITH THE NUMBER ZERO.  /
 /  LDA $D011  /  LOAD THE ACCUMULATOR
WITH THE CONTENTS OF ADDRESS $D011.  /
 /  STA $0400  /  STORE THE
ACCUMULATOR INTO ADDRESS $0400.  /

PART B: HASH OR NO HASH

 /  A  /  B  /  DIFFERENCE  /
 /  LDA #$10  /  LDA $10  /  A LOADS
THE NUMBER SIXTEEN. B GOES TO ADDRESS
$0010 AND LOADS WHATEVER IS THERE.  /

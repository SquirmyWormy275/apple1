THE BYTE QUESTION

$A0 AT $0300 IS ALL OF THESE,
DEPENDING. THE CORRECT REASON: MEMORY
DOES NOT RECORD WHAT KIND OF THING A
BYTE IS. ONLY THE PROGRAM'S TREATMENT
OF IT DECIDES. IF THE CPU FETCHES IT
AS AN OPCODE IT IS LDY IMMEDIATE; IF A
PROGRAM LOADS AND COMPARES IT, IT IS
THE NUMBER 160; IF IT GOES TO THE
DISPLAY IT IS A CHARACTER CODE WITH

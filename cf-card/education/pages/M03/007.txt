TWO THINGS ARE WORTH NOTICING. THE
SCREEN AND THE BUFFER AGREE, WHICH IS
THE PROGRAM WORKING: IT STORES EACH
CHARACTER AND ECHOES IT. AND THE
INSTRUCTION COUNT FOLLOWS A PATTERN,
TEN PER CHARACTER PLUS TEN, WHICH LETS
YOU PREDICT A RUN YOU HAVE NOT DONE.

REPRODUCIBLE MEANS IT GIVES THE SAME
ANSWER EVERY TIME. SAME BYTES, SAME
INPUT, SAME FOUR NUMBERS. IF YOU GET
SOMETHING DIFFERENT, THE INTERESTING
QUESTION IS WHAT DIFFERED: A CHANGED
BYTE, A DIFFERENT INPUT, A DIFFERENT
VERSION OF THE HARNESS. A RUN THAT
VARIES BETWEEN ATTEMPTS IS TELLING YOU
SOMETHING IS NOT PINNED DOWN.

IT IS A PLAYBACK STAGE. IT RESETS THE
POSITION TO ZERO AND WALKS THE BUFFER,
ECHOING EACH BYTE UNTIL IT HITS THE
STORED CARRIAGE RETURN. STRUCTURALLY
IT IS THE SAME LOOP AS THE INPUT STAGE
WITH THE INPUT STEP REMOVED: READ FROM
MEMORY RATHER THAN FROM THE KEYBOARD.

WHERE IT FITS: IT REPLACES THE RETURN
STAGE RATHER THAN ADDING TO IT.
INSTEAD OF HANDING CONTROL BACK, THE
PROGRAM PLAYS THE BUFFER BACK AND THEN
JUMPS TO ITS OWN START. SO THE
SIX-STAGE SCHEME BECOMES SETUP, INPUT,
STORE, ECHO, TEST, PLAYBACK, RESTART,
WITH NO RETURN STAGE AT ALL.

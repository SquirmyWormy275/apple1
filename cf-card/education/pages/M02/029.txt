029/032 ANSWERS


EIGHT PER LINE IS EASIER TO CHECK BY
EYE, BECAUSE A DIFFERENCE BETWEEN TWO
SHORT COLUMNS IS VISUALLY OBVIOUS
WHILE A DIFFERENCE BETWEEN TWO LONG
LINES IS NOT, AND BECAUSE EACH LINE
CARRIES ITS OWN ADDRESS SO YOU CAN
LOCATE AN ERROR RATHER THAN JUST
DETECT ONE. IT ALSO MATCHES WHAT THE
MONITOR PRINTS, SO A LISTING AND A
SCREEN CAN BE COMPARED LINE AGAINST
LINE.

THE SINGLE RUN IS BETTER FOR STORAGE
AND FOR TOOLING. IT HAS NO FORMATTING
TO PARSE, NO ADDRESSES THAT COULD
DISAGREE WITH THE FILENAME, AND NO WAY
FOR A LINE LABEL TO DRIFT OUT OF STEP

M02 ADDRESSES AND BYTE ENTRY
005/032 LEARN

THE SAME BYTES AT A DIFFERENT ADDRESS
ARE A DIFFERENT PROGRAM. THIS IS THE
PART THAT SURPRISES PEOPLE. BYTES THAT
REFER TO ADDRESSES, LIKE A JUMP,
CONTAIN THOSE ADDRESSES INSIDE
THEMSELVES. MOVE THE PROGRAM WITHOUT
CHANGING THEM AND THE JUMPS STILL
POINT WHERE THEY ALWAYS DID, WHICH IS
NOW THE WRONG PLACE.

SOME BYTES ARE WORSE THAN THAT. A
BRANCH USES A *RELATIVE* OFFSET, SO IT
MOVES WITH THE PROGRAM CORRECTLY. A
JUMP USES AN ABSOLUTE ADDRESS AND DOES
NOT. A LISTING MOVED WHOLESALE TO A
NEW ADDRESS IS USUALLY A PROGRAM THAT
RUNS FOR A FEW INSTRUCTIONS AND THEN
GOES SOMEWHERE MEANINGLESS.

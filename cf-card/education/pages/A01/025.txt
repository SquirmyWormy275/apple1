LDA $D011 READS THE KEYBOARD CONTROL
REGISTER AND LOADS WHATEVER IS THERE
RIGHT NOW. THIS ONE CAN PRODUCE A
DIFFERENT RESULT EACH TIME IT RUNS,
BECAUSE $D011 IS A HARDWARE REGISTER
WHOSE CONTENTS CHANGE WHEN A KEY IS
PRESSED.

THAT DIFFERENCE IS THE REASON THE
PROGRAM IN PART E LOOPS ON IT: READING
IT REPEATEDLY IS ONLY USEFUL IF THE
ANSWER CAN CHANGE.

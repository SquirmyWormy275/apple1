007/008 K04 SAVE AND RESTORE BASIC IN 

EVIDENCE MODE: CFFA1_FIRMWARE

THE INTERPRETER TOKENIZES THE AUTHORED
PROGRAM. CFFA1 SAVEBASICFILE EMITS ITS
A1 HEADER AND $F1 FILE; LOADBASICFILE
RESTORES STATE INTO CLEARED RAM. A
BASIC WARM START THEN EXECUTES THE
RESTORED PROGRAM.

TRY: WHY WOULD RENAMING A .BAS TEXT
FILE TO A BASIC FILENAME BE
INSUFFICIENT?

CHECK: CFFA1 BA1 STORES INTERPRETER
STATE AND TOKENIZED MEMORY, INCLUDING
A VERSIONED HEADER. PLAIN SOURCE TEXT
IS A DIFFERENT FORMAT. USE THE
INTERPRETER AND SAVE API RATHER THAN A
N NEXT P BACK A ANSWER M BOOK Q EXIT

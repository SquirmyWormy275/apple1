PART E: THE HANDOVER

A PROGRAM MUST RETURN CONTROL
DELIBERATELY, BECAUSE NOTHING WILL DO
IT FOR THEM. IF A PROGRAM RUNS OFF THE
END OF ITS OWN INSTRUCTIONS, THE CPU
DOES NOT NOTICE OR STOP. IT CARRIES ON
FETCHING WHATEVER BYTES COME NEXT AND
EXECUTING THEM AS INSTRUCTIONS, WHICH
WILL BE LEFTOVER DATA OR UNWRITTEN
MEMORY. THE BEHAVIOR FROM THAT POINT
IS UNDEFINED AND THE USUAL OUTCOME IS
THAT THE MACHINE STOPS RESPONDING AND
HAS TO BE RESET.

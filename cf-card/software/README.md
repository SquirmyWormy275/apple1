# CF-card software candidates

Authoritative source: `software/ram-only/`.

Current artifacts include the two RAM-only line-input programs and their README.
They remain **RAM-only candidates with no live-run authority**. The CF-card
manifest indexes the directory for future planning but excludes it from the
default export.

Putting a file in a host-side staging tree would not authorize loading or
running it on the Replica 1 Plus.

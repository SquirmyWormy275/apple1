The attached 128,974,848-byte Lexar CF card contained only its original software.
Its full pre-write SHA-256 matched the August 28 preservation baseline exactly.
The educational source existed in the repo, but the physical delivery layer
had not been built or installed: the existing exporter only staged SP01 text.

in full. All 128,974,848 readback bytes match the checked image. The first
ProDOS volume now contains 524 files: six original files and 518 additions,
with about 21.4 MiB free. [Machine-readable receipt](deployments/2026-10-27.json).

## First use

At the CFFA1 menu, select the root with `P` and an empty directory name, load
`START.HERE` with `L`, accept `$1000`, then use `Q` to return to Monitor and
enter `1000R`. Space advances, B goes back, Q returns to Monitor. Begin learning
with `START/S01.READ` using the same load-and-run sequence.

See the [full reading and rebuilding guide](DEPLOYMENT.md).
